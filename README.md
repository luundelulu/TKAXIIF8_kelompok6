# Survei Kesiapan TKA

Web sederhana untuk menampilkan hasil survei kesiapan TKA kelas XII F8.
Buka `index.html` langsung di browser (tanpa server).

- `index.html` : struktur halaman
- `style.css` : tampilan (tema terang, warna netral)
- `script.js` : logika (graf node berputar, pindah tab, ringkasan, tabel, cari/urut responden)
- `data.js` : data survei (email dihapus)

Dibuat oleh Kelompok 6.
